# 长输天然气管网 · 压力异常处置推演系统

在管线剖面上追踪压力异常的逐站传播过程，演练隔离管段、压缩机降负荷、改供气路径等处置动作，
并对动作审批、超时失效、撤销、现场设备反馈核实与“从稳定状态重演”提供完整闭环。

零第三方依赖，Node.js ≥ 18 即可运行。

## 运行

```bash
npm start          # http://localhost:5173
npm test           # 9 个引擎/台账端到端用例
PORT=8080 npm start
```

## 内置剧本

- 管网：1 个气源首站、2 座压气站（C1/C2）、7 个阀室、2 个需求门站（东部/末段区域），另有一条 C1—G3 联络支线（终点阀 V7 常关）。
- `T+3`：G2—G3 管段中部发生约 42 万m³/d 泄漏；先出现“流量平衡异常”预警，随后确认泄漏。
- `T+60`：现场采集/控制服务中断 12 分钟（也可用工具栏手动模拟任意中断/恢复）。

建议处置顺序：封堵泄漏 → C2 降负荷 → 关闭 V4 隔离 G2—G3 → 开启 V7 改由联络线供气。
错误顺序（例如 C2 仍带负荷先关出站阀 V8）会产生憋压并形成新的超压点，提交时会被风险预检标红。

## 功能与实现对照

| 需求 | 实现 |
| --- | --- |
| 压力波、压缩机、阀门、供气方向、泄漏区段 | `src/engine.js`：BFS 供气树 + 沿程压降/压气站升压 + 管段延迟波（20 km/tick）+ 压差决定方向 |
| 压力变化逐站传播 | 目标压力变化生成在途波，按管段长度延迟到达，站点显示压力平滑跟踪；关阀/封堵会作废旧波 |
| 隔离/降负荷/改供气路径 | 阀门开关、压缩机负荷指令；改路示例为关 V4 + 开 V7，联络线出现反向/新增流向 |
| 重新计算最低供应 | 区域按连通性、到站压力折减供气量，输出 可维持 / 减量 / 无法维持（`regionStatus`） |
| 错误关阀扩大异常/新超压点 | 带负荷压气站出站截断触发憋压（压力逐拍上升）；关阀风险预检提示切断保供、憋压、压差冲击 |
| 动作审批 | 操作员提交 → 调度主管批准；前端右上角切换角色 |
| 超时失效 | 待审批 10 tick、执行窗口 8 tick；现场离线期间执行窗口顺延 |
| 撤销未执行指令 | 待审批/已批准指令可随时撤销；已执行指令可凭下发前快照“撤销并还原” |
| 服务中断/恢复核实 | 中断时水力推演暂停、已批准指令挂起；恢复后进入核对态，逐条确认“反馈一致/不一致”，不一致自动回滚动作 |
| 从稳定状态重演 | 管网稳定后自动留快照（也可手动）；重演回退压力/阀门/负荷/泄漏与台账，其后指令作废、事件链留痕 |

## 主要 API

- `GET /api/state` 全量状态（站点压力、管段流向/阀门、泄漏、报警、区域、指令台账、事件、快照）
- `POST /api/advance {steps}` / `POST /api/run {on}` 单步/自动推演
- `POST /api/preflight {type,ref,payload}` 动作风险预检（不产生指令）
- `POST /api/commands` 提交；`/api/commands/:id/approve|reject|cancel` 审批/驳回/撤销
- `POST /api/reconcile {id,matched,note}` 恢复后的设备反馈核对
- `POST /api/undo {id,reason}` 撤销已生效指令并还原设备状态
- `POST /api/gateway {online}` 现场服务中断/恢复
- `POST /api/leak {edge,rate,offset}` 人工注入泄漏
- `POST /api/snapshots`、`POST /api/replay {id}` 快照与重演；`POST /api/reset` 重置

## 模型边界

推演级模型（非工业水力仿真）：压力为沿供气树的显式稳态+延迟波近似，流量为子树需求汇总，
未涉及压缩机组特性曲线、组分/温度、非稳态管网联立求解。模型参数（波速、压降系数、MAOP、
最低保障压力、TTL 等）集中在 `src/scenario.js` 与 `src/engine.js` 顶部，便于按教学需要调整。

## 目录

- `src/scenario.js` 管网拓扑、区域与剧本事件
- `src/engine.js` 水力/压力波、报警、泄漏、保供评估、现场服务与快照
- `src/commands.js` 指令台账：风险预检、审批/超时/撤销、下发与回滚
- `src/state.js` 快照恢复与重演
- `src/server.js` 零依赖 HTTP 服务
- `web/` 原生前端（SVG 管线剖面 + 工作流面板）
- `test/engine.test.js` 端到端用例
