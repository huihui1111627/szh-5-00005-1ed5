# 长输天然气管网 · 压力异常应急处置推演台

单文件、零依赖的交互式 SCADA 仿真原型，直接用浏览器打开 `index.html` 即可运行。

## 功能对照需求

- **管线剖面监视**：SVG 剖面展示 16 个节点（气源/阀室/分输/压气站/末端）、管段压力着色、
  流向粒子、阀门状态（开=绿叉、关=红叉）、压缩机风扇、泄漏点脉冲标识。
- **压力波动逐站传播**：注入泄漏后扰动沿拓扑逐拍扩散，紫色波环在各站到达时刻扩散，
  事件日志记录「压力扰动到达 XX 站」；下方 Canvas 趋势图显示关键站压力与供气率。
- **三类处置动作**：
  - 隔离管段（多步宏：降 C1 → 关上游阀 → 关下游阀 → 降 C2 → 开联络阀）
  - 压缩机负荷调整（0–100%）
  - 改变供气路径（开/关气源 B 联络阀）
- **区域最低供应重算**：南区 / 中部 / 北区实时核算供气保障率、最低压力、达标/低压/危机三态；
  隔离段内用户自动从保障分母剔除并标注「已隔离」。
- **错误关阀顺序的后果**：先关下游阀（不先降负荷）会在 F1 形成超压点、并使 C2 抽空跳闸，
  北区失去保障。提交表单时给出 ⛔/⚠/✓ 三级风险预检。
- **指令生命周期**：PENDING 待审批（45 秒 TTL 倒计时条，超时自动 EXPIRED）→
  APPROVED → EXECUTING（宏步骤每 3 拍执行一步）→ DONE；可驳回；
  已批准但未执行（或未执行完）的步骤可随时撤销，已执行步骤保留。
- **超时失效**：45 秒未审批的指令自动标记 EXPIRED 并写入日志。
- **稳定状态重演**：系统自动在压力收敛、无报警时捕获快照（含基线事故前快照）；
  可从任一快照按原始时间节拍重放全部已记录操作（重演中审批自动通过），可随时退出回到现场。
- **通信中断与恢复核验**：中断期间新指令无法审批、已执行指令缺现场反馈；
  恢复后弹出设备反馈核验窗（期望值 vs 现场反馈，卡阻/未关严偏差需逐项勾选核实），
  全部核实后才允许「续跑」，也可终止未确认指令。

## 建议操作路径

1. 点右上「⚡ 注入泄漏 F2–F3」，观察压力波逐站传播与北区供气率下降。
2. 在「调度指令」选「隔离管段（多步宏）」，先用「先关下游阀（错误顺序）」提交并批准，
   观察 F1 超压报警与 C2 抽空跳闸；点「复位基线」。
3. 重新注入泄漏，用「标准规程」提交批准，观察五步骤顺序执行、隔离段转红虚线、
   联络阀转供、三区保障率恢复 100%。
4. 可尝试「📡 中断通信」后再恢复，体验现场反馈核验；处置稳定后点「↺ 稳定点重演」。

## 模型说明

集总参数水力模型：普通管段按导纳做 Jacobi 压力松弛（无条件稳定，天然呈现逐站传播迟滞）；
压缩机以「目标出口压力（随负荷）+ 流量上限 + 止回 + 抽空联锁跳闸 + 吸入恢复自动复位」建模；
泄漏为泄漏中点对大气的导纳，关两侧截断阀后残余导纳降至 0.8%。参数为教学演示标定，非工程数值。

## 校验

`node` 无头测试（47 项）覆盖：基线稳态、泄漏跌落、错误顺序超压/抽空、
标准规程隔离转供恢复、TTL 超时、撤销未执行步骤、通信核验、快照与重演。
